# Alexa+ media assets

Required before `alexa-ai deploy` will succeed:

- **Icons, light theme — all six sizes are mandatory:** 72×72, 64×64, 88×88,
  126×126, 180×180, 241×241
- **At least one carousel image** at 600×900

All URIs must be HTTPS, and PNG / JPG / JPEG / WEBP.

Also required: two **live** HTTPS pages — a privacy policy and terms of use.

Generate all of this in week one. It gates deployment and it is always
underestimated.
