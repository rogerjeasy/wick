A simulated Alexa+ surface. Real account, real Wick server, real tools. Why simulated?

Amazon's Alexa+ add-on tools are open to select partners only, so this page stands in for the assistant, as the hackathon permits. Nothing on it is canned: you sign in to a real account, a model chooses which of Wick's tools to call, and this page calls them on the real Wick MCP server (spec 2025-11-25, Streamable HTTP, OAuth 2.1). Every fact it says comes from a tool's answer.
